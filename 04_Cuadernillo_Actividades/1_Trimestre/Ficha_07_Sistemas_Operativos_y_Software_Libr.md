## FICHA DE ACTIVIDADES N° 7 | Sistemas Operativos y Software Libre
* **Módulo 1:** Alfabetización Informática-Computacional | **Clase:** 7
* **Objetivo:** Distinguir las funciones del Sistema Operativo y debatir las libertades del Software Libre (Huayra Linux) vs. Software Propietario.

#### ACTIVIDAD DESENCHUFADA (En Carpeta)
1. **Funciones Clave:** Anotá las 3 funciones principales que cumple cualquier Sistema Operativo en una máquina.
2. **Las 4 Libertades de Richard Stallman:** Relacioná cada libertad con su significado práctico:
   * **Libertad 0:** [ ] Distribuir copias para ayudar al prójimo.
   * **Libertad 1:** [ ] Usar el programa con cualquier fin (educativo, comercial, personal).
   * **Libertad 2:** [ ] Publicar tus mejoras para que toda la sociedad se beneficie.
   * **Libertad 3:** [ ] Estudiar el código fuente y modificarlo para lo que necesites.
